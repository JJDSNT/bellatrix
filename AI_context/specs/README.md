# AI_context/specs

## Purpose

Formal specifications — the source of definition from which issues can be
derived (optional `spec_id` in the issue frontmatter).

## Allowed statuses

`draft`, `validated`, `active`, `deprecated`

## Versioning

There is no version table: a spec's history is the git log of its own file.
