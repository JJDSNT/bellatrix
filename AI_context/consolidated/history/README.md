# Histórico de issues

Este diretório guarda issues concluídas, resolvidas, substituídas ou absorvidas.
Elas preservam decisões, causas e evidências úteis, mas **não representam
pendências** e seus checklists antigos não formam backlog.

Regras:

- `AI_context/issues/` contém somente trabalho realmente ativo;
- ao encerrar ou substituir uma issue, mover o documento para este diretório;
- transportar para uma issue ativa apenas a pendência que ainda for necessária;
- planos históricos não podem sobrepor a arquitetura canônica mais recente;
- para performance/multicore, a especificação vigente é `ISSUE-0051` e o único
  tracker operacional é `ISSUE-0052`.
